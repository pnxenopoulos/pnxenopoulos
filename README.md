## Projects

- **[Boon](https://github.com/pnxenopoulos/boon)** — A Rust parser for Deadlock replays with Python bindings and a command-line interface.
- **[deadlock.nyc](https://deadlock.nyc/)** — A browser-based Deadlock replay analyzer with tick-level playback and on-device win probability predictions. It parses replays locally using Boon compiled to WebAssembly.
- **[Awpy](https://github.com/pnxenopoulos/awpy)** — A Counter-Strike replay analytics library with a Rust parser and Python API.
- **[ESTA](https://github.com/pnxenopoulos/esta)** — An open esports dataset with 8.6 million player actions and 7.9 million game frames from 1,558 professional Counter-Strike replays.
